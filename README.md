# Chatterduo website

Marketing site for **Chatterduo**, a face-to-face conversation translator for iPhone and iPhone Duo.

This repository is the website only. App source is not kept here.

## URLs

- Live (GitHub Pages): https://erdtheturd.github.io/chatterduo/
- Future custom domain: https://chatterduo.com (not connected yet)

## Pages

- `index.html` — product overview
- `privacy.html` — Privacy Policy
- `support.html` — Support and FAQ

Support: [support@chatterduo.com](mailto:support@chatterduo.com)

Static HTML and CSS. No build step, packages, or tracking scripts.
